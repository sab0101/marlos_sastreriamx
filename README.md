# marlos_sastreriamx# Marlo's Sastrería

Sitio estático (HTML, CSS y JS). Sin dependencias ni build.

## Estructura
```
index.html
css/styles.css
js/main.js
README.md
```

## Antes de publicar
- `index.html`: dirección, teléfono, horario (sección Contacto).
- `js/main.js`: número de WhatsApp en `WHATSAPP`.

## Publicar en GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.
